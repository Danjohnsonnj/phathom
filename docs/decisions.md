## Active invariants index

- **Privacy:** Local-only; no CloudKit / sync (`ContentItem`, etc.).
- **Schema highlights:** JSON strings for summaries/extract fields; granular `processingStatus`; `Category` relational; **`sourceMarkdown`** + UTF-16 **`Highlight`** anchors; backup envelope **v4** + optional **`categoryName`** per item + **`focusEntry`** / **`focusOutcomes[]`** (`LibraryBackupService`).
- **Inference:** Sole engine **Llama.cpp** via vendored xcframework; serialized **`withSession`**; optional **tagging GGUF** with primary fallback; **KV prefix reuse** for summarize/extract path; Llama‑3-ish chat templates.
- **Pipeline / ingest:** GGUF **security-scoped bookmarks**; offline-tolerant web pending; **`MainContentExtractor`** for generic HTML; **`sourceMarkdown`** cap; **`BGProcessingTask` `requiresExternalPower = false`** for analyze (revisit only if jetsam/thermal warrants).
- **UI / Library:** **`ReadStatus`** + filters; **`LibrarySearchService`** **`filterCategory`**; granular **`ProcessingStatusPresentation`**; Mail-style swipe read-state; archive = soft-delete **48h** + Spotlight de-index/re-index; **`phathomDidArchiveItem`** batch undo — see [`library-bulk-selection.md`](archive/library-bulk-selection.md). **Notebook tab:** cross-item highlight feed grouped by **`ContentItem`** — see **2026-05-30** rows; **`NotebookHighlightsQuery`**, **`HairlineHighlightRow`** in Notebook feed and Detail highlights. **Push nav:** **`DetailPushNavBar`** hides system back; **`NavigationInteractivePopEnabler`** restores native edge-swipe pop — see **2026-05-31** row.
- **Archive / recovery:** Undo snackbar + Recently Deleted perf pattern; archiving **cancels in-flight pipeline** slices; **`PipelineWorkGate.performActiveWebQueueReset`** rules.
- **Spotlight:** Tag keywords only (**category omitted** deliberately); **`titleUserSet`** preserves user titles.
- **Focus Stack v1 (shipped):** **Focus tab** replaced **Chat** in tab row (**Library · Notebook · Focus · Add New**). **Cap 7** + swap (Release-only). Outcomes: Reference · Takeaway · Revisit · Release. Library trailing **scope** (in Focus) or **clock** (revisit due); Detail **Focus row** + **closure indicator**; stale tint + nudge + weekly prompt. Backup **v4** includes Focus rows. **`ReadStatus`** orthogonal (`filed` = shelf). Spec: [`focus-stack.md`](handoff/focus-stack.md) · delivery: [`focus-stack-delivery.md`](handoff/focus-stack-delivery.md).
- **RAG / Chat (deferred):** Standalone **Chat tab removed**; open RAG **not scheduled** — may re-scope to thread-scoped assist (Phase C). Schema retains **`ChatThread`** / **`ChatMessage`**. Hand-off: [`phase-3-rag-chat.md`](handoff/phase-3-rag-chat.md).
- **Detail media (hero + View Photo):** New captures store **1024px / 0.72** JPEG via **`normalizedJPEGForLibraryStorage`**; Detail decode subsamples via ImageIO capped at **`libraryStorageMaxDimension`**; in-memory cache + load coalesce + Library prewarm; **`fullScreenCover(item:)`** + **`PhotoZoomScrollView`** for full-screen viewer. Target **≤3s** cold Library → Detail hero on new captures; **legacy rows** not backfilled. Opt-in traces: **`-MediaImageProfiling`** / **`phathom.mediaImageProfiling`** → filter **`[Phathom.Media]`**.
